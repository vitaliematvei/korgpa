Pot exista cazuri în care este nevoie să stilizezi un element în mod condiționat, în funcție de o stare (_state_) sau o altă condiție.

**`clsx`** este o bibliotecă ce îți permite să comuți numele claselor cu ușurință.
Îți recomandăm să arunci o privire peste documentație pentru mai multe detalii, dar iată modul de bază de utilizare:

Presupunem că vrei să creezi un component `InvoiceStatus` care primește un prop numit `status`.
Starea `status` poate fi `'pending'` (în așteptare) sau `'paid'` (plătită).

- Dacă este `'paid'`, vrei ca culoarea să fie verde.
- Dacă este `'pending'`, vrei ca culoarea să fie gri.

Poți folosi `clsx` pentru a aplica clasele condiționat, astfel:

`/app/ui/invoices/status.tsx`

```tsx
import clsx from 'clsx';

export default function InvoiceStatus({ status }: { status: string }) {
  return (
    <span
      className={clsx(
        'inline-flex items-center rounded-full px-2 py-1 text-sm',
        {
          'bg-gray-100 text-gray-500': status === 'pending',
          'bg-green-500 text-white': status === 'paid',
        },
      )}
    >
      {/* ... */}
    </span>
  );
}
```
