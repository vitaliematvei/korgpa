## CSS Modules

**CSS Modules** îți permit să limitezi domeniul de aplicare (_scope_) al CSS-ului la nivelul unui singur component, generând automat nume de clase unice, astfel încât să nu-ți faci griji în privința conflictelor de stiluri (_style collisions_).

Vom continua să folosim Tailwind în acest curs, dar hai să luăm un moment pentru a vedea cum poți obține aceleași rezultate din exercițiul anterior folosind CSS Modules.

În interiorul `/app/ui`, creează un fișier nou numit `home.module.css` și adaugă următoarele reguli CSS:

`/app/ui/home.module.css`

```css
.shape {
  height: 0;
  width: 0;
  border-bottom: 30px solid black;
  border-left: 20px solid transparent;
  border-right: 20px solid transparent;
}
```

Apoi, în fișierul `/app/page.tsx`, importă stilurile și înlocuiește clasele Tailwind ale elementului `<div>` pe care l-ai adăugat cu `styles.shape`:

`/app/page.tsx`

```tsx
import AcmeLogo from '@/app/ui/acme-logo';
import { ArrowRightIcon } from '@heroicons/react/24/outline';
import Link from 'next/link';
import styles from '@/app/ui/home.module.css';

export default function Page() {
  return (
    <main className="flex min-h-screen flex-col p-6">
      <div className={styles.shape} />
      {/* ... */}
    </main>
  );
}
```

Salvează modificările și vezi previzualizarea în browser. Ar trebui să vezi aceeași formă ca înainte.

**Tailwind** și **CSS Modules** sunt cele mai comune două metode de stilizare a aplicațiilor Next.js. Alegerea uneia sau alteia ține de preferințele personale — poți chiar să le folosești pe ambele în cadrul aceleiași aplicații!
