În Capitolul 3, ai importat fontul Inter într-o altă machetă: `/app/layout.tsx`.
Ca o reamintire:

`/app/layout.tsx`

```tsx
import '@/app/ui/global.css';
import { inter } from '@/app/ui/fonts';

export default function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <html lang="en">
      <body className={`${inter.className} antialiased`}>{children}</body>
    </html>
  );
}
```

Aceasta se numește **machetă rădăcină** (_root layout_) și este obligatorie în orice aplicație Next.js.
Orice element de interfață (UI) pe care îl adaugi în macheta rădăcină va fi partajat pe toate paginile din aplicație.
Poți folosi macheta rădăcină pentru a modifica etichetele `<html>` și `<body>` și pentru a adăuga metadate (vei învăța mai multe despre metadate într-un capitol ulterior).

Deoarece noua machetă pe care tocmai ai creat-o (`/app/dashboard/layout.tsx`) este specifică paginilor de dashboard, nu este nevoie să adaugi nicio interfață în macheta rădăcină de mai sus.
