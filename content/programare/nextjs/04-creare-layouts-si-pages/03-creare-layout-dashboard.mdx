Dashboard-urile au un tip de navigare care este partajat între mai multe pagini.
În Next.js, poți folosi un fișier special `layout.tsx` pentru a crea o interfață de utilizator (UI) partajată între mai multe pagini.
Hai să creăm o machetă pentru paginile din dashboard!

În interiorul dosarului `/dashboard`, adaugă un fișier nou numit `layout.tsx` și lipește următorul cod:

`/app/dashboard/layout.tsx`

```tsx
import SideNav from '@/app/ui/dashboard/sidenav';

export default function Layout({ children }: { children: React.ReactNode }) {
  return (
    <div className="flex h-screen flex-col md:flex-row md:overflow-hidden">
      <div className="w-full flex-none md:w-64">
        <SideNav />
      </div>
      <div className="grow p-6 md:overflow-y-auto md:p-12">{children}</div>
    </div>
  );
}
```

Se întâmplă câteva lucruri în acest cod, așa că hai să le analizăm detaliat:

Mai întâi, imporți componentul `<SideNav/>` în macheta ta.
Orice component pe care îl imporți în acest fișier va face parte din machetă.

Componentul `<Layout/>` primește un prop `children`.
Acest fiu (_child_) poate fi fie o pagină, fie o altă machetă.
În cazul tău, paginile din interiorul `/dashboard` vor fi imbricate automat în interiorul unui `<Layout/>`, astfel:

Un avantaj al utilizării machetelor (_layouts_) în Next.js este că, la navigare, doar componentele paginii se actualizează, în timp ce macheta nu este rerandată (_re-render_).
Acest proces se numește **randare parțială** (_partial rendering_) și ajută la păstrarea stării React de pe partea de client (_client-side state_) din machetă în timpul tranziției dintre pagini.
