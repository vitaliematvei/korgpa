În Next.js, poți folosi componenta `<Link/>` pentru a crea legături între paginile aplicației tale.
`<Link>` îți permite să realizezi o navigare pe partea de client (_client-side navigation_) folosind JavaScript.

Pentru a utiliza componenta `<Link/>`, deschide fișierul `/app/ui/dashboard/nav-links.tsx` și importă componenta din `next/link`.
Apoi, înlocuiește eticheta `<a>` cu `<Link>`:

```tsx
// /app/ui/dashboard/nav-links.tsx
import {
  UserGroupIcon,
  HomeIcon,
  DocumentDuplicateIcon,
} from '@heroicons/react/24/outline';
import Link from 'next/link';

// ...

export default function NavLinks() {
  return (
    <>
      {links.map((link) => {
        const LinkIcon = link.icon;
        return (
          <Link
            key={link.name}
            href={link.href}
            className="flex h-[48px] grow items-center justify-center gap-2 rounded-md bg-gray-50 p-3 text-sm font-medium hover:bg-sky-100 hover:text-blue-600 md:flex-none md:justify-start md:p-2 md:px-3"
          >
            <LinkIcon className="w-6" />
            <p className="hidden md:block">{link.name}</p>
          </Link>
        );
      })}
    </>
  );
}
```

După cum poți observa, componenta `Link` este similară cu etichetele `<a>`, dar în loc de `<a href="...">` folosești `<Link href="...">`.

Salvează modificările și verifică dacă funcționează în `localhost`. Ar trebui să poți naviga între pagini fără să mai vezi o reîmprospătare completă a ecranului. Deși anumite părți ale aplicației tale sunt randate pe server, pagina nu se mai reîncarcă de la zero, oferind senzația unei aplicații web native.
