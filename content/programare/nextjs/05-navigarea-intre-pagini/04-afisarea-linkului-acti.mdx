Un model vizual (_UI pattern_) foarte comun este evidențierea linkului activ pentru a-i indica utilizatorului pe ce pagină se află în acel moment.
Pentru a realiza acest lucru, trebuie să obții calea (_path_) curentă din URL.
Next.js oferă un hook numit `usePathname()` pe care îl poți folosi pentru a verifica calea și a implementa acest comportament.

Deoarece `usePathname()` este un hook React, va trebui să transformi fișierul `nav-links.tsx` într-o componentă de client (_Client Component_).
Adaugă directiva React `'use client'` în partea de sus a fișierului, apoi importă `usePathname()` din `next/navigation`:

```tsx
// /app/ui/dashboard/nav-links.tsx
'use client';

import {
  UserGroupIcon,
  HomeIcon,
  DocumentDuplicateIcon,
} from '@heroicons/react/24/outline';
import Link from 'next/link';
import { usePathname } from 'next/navigation';

// ...
```

În continuare, atribuie calea unei variabile numite `pathname` în interiorul componentei tale `<NavLinks/>`:

```tsx
// /app/ui/dashboard/nav-links.tsx
export default function NavLinks() {
  const pathname = usePathname();
  // ...
}
```

> **Notă:** Fișierul `nav-links.tsx` nu este un fișier special pentru Next.js — îi poți da orice nume dorești.
> Dacă îl redenumști, asigură-te doar că actualizezi instrucțiunile de import corespunzător.

Poți folosi biblioteca `clsx` (prezentată în capitolul despre stilizarea CSS) pentru a aplica clase mod condiționat atunci când linkul este activ.
Când `link.href` se potrivește cu `pathname`, linkul ar trebui afișat cu text albastru și un fundal albastru deschis.

Iată codul final pentru `nav-links.tsx`:

```tsx
// /app/ui/dashboard/nav-links.tsx
'use client';

import {
  UserGroupIcon,
  HomeIcon,
  DocumentDuplicateIcon,
} from '@heroicons/react/24/outline';
import Link from 'next/link';
import { usePathname } from 'next/navigation';
import clsx from 'clsx';

// ...

export default function NavLinks() {
  const pathname = usePathname();

  return (
    <>
      {links.map((link) => {
        const LinkIcon = link.icon;
        return (
          <Link
            key={link.name}
            href={link.href}
            className={clsx(
              'flex h-[48px] grow items-center justify-center gap-2 rounded-md bg-gray-50 p-3 text-sm font-medium hover:bg-sky-100 hover:text-blue-600 md:flex-none md:justify-start md:p-2 md:px-3',
              {
                'bg-sky-100 text-blue-600': pathname === link.href,
              },
            )}
          >
            <LinkIcon className="w-6" />
            <p className="hidden md:block">{link.name}</p>
          </Link>
        );
      })}
    </>
  );
}
```

Salvează și verifică în `localhost`. Ar trebui să vezi acum linkul activ evidențiat cu albastru!
