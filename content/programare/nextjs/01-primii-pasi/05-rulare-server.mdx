### Rularea serverului de dezvoltare

Rulează `pnpm i` pentru a instala pachetele proiectului:

**Terminal**

```bash
pnpm i

```

Urmat de `pnpm dev` pentru a porni serverul de dezvoltare:

**Terminal**

```bash
pnpm dev

```

Comanda `pnpm dev` pornește serverul tău de dezvoltare Next.js pe portul 3000. Haidem să verificăm dacă funcționează.

Deschide `http://localhost:3000` în browser.
