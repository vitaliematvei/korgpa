### Date simulate (Placeholder data)

Când construiești interfețe de utilizator, este de ajutor să ai niște date de probă. Dacă o bază de date sau un API nu sunt încă disponibile, poți:

- Să folosești date simulate în format JSON sau sub formă de obiecte JavaScript.
- Să folosești un serviciu extern (3rd party), cum ar fi mockAPI.

Pentru acest proiect, am furnizat câteva date simulate în fișierul `app/lib/placeholder-data.ts`. Fiecare obiect JavaScript din fișier reprezintă un tabel din baza ta de date. De exemplu, pentru tabelul de facturi (`invoices`):

**/app/lib/placeholder-data.ts**

```typescript
const invoices = [
  {
    customer_id: customers[0].id,
    amount: 15795,
    status: 'pending',
    date: '2022-12-06',
  },
  {
    customer_id: customers[1].id,
    amount: 20348,
    status: 'pending',
    date: '2022-11-14',
  },
  // ...
];
```

În capitolul despre configurarea bazei de date, vei folosi aceste date pentru a popula baza de date (_seed your database_ — adică pentru a o umple cu date inițiale).
