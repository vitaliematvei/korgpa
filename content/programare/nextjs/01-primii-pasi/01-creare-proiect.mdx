Îți recomandăm să folosești **pnpm** ca administrator de pachete (package manager), deoarece este mai rapid și mai eficient decât npm sau yarn.
Dacă nu ai pnpm instalat, îl poți instala la nivel global rulând:

**Terminal**

```bash
npm install -g pnpm

```

Pentru a crea o aplicație Next.js, deschide terminalul, navighează (`cd`) în folderul în care dorești să îți păstrezi proiectul și rulează următoarea comandă:

**Comanda de instalare:**

`npx create-next-app@latest nextjs-dashboard`
`--example "https://github.com/vercel/next-learn/tree/main/dashboard/starter-example"`
`--use-pnpm`

Această comandă folosește `create-next-app`, un instrument CLI (Interfață în Linie de Comandă) care configurează o aplicație Next.js pentru tine. În comanda de mai sus, folosești și parametrul `--example` împreună cu proiectul de pornire (starter example) destinat acestui curs.
