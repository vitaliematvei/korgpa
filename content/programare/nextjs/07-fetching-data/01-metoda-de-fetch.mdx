#### Stratul API (API layer)

API-urile reprezintă un strat intermediar între codul aplicației și baza de date.
Există câteva cazuri în care este recomandat să folosești un API:

- Dacă utilizezi servicii terțe (_third-party_) care oferă un API.
- Dacă preiei date de pe client, ai nevoie de un strat API care rulează pe server pentru a evita expunerea datelor confidențiale ale bazei de date (_database secrets_) către client.

În Next.js, poți crea endpoint-uri API folosind **Route Handlers**.

#### Interogările bazei de date (Database queries)

Când construiești o aplicație full-stack, va trebui să scrii logica prin care interacționezi cu baza de date.
Pentru bazele de date relaționale (cum ar fi Postgres), poți face acest lucru folosind SQL sau un ORM.

Există câteva situații în care este necesar să scrii interogări pentru baza de date:

- Când creezi endpoint-urile API și trebuie să incluzi logica de interacțiune cu baza de date.
- Dacă folosești **React Server Components** (preluarea datelor direct pe server), poți omite stratul API și poți interoga baza de date direct, fără riscul de a expune datele confidențiale către client.
