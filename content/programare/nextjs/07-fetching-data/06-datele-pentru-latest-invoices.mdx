Pentru componenta `<LatestInvoices/>`, trebuie să obținem ultimele 5 facturi, sortate după dată.

Ai putea prelua toate facturile și să le sortezi ulterior folosind JavaScript.
Această abordare nu este o problemă când volumul de date este mic, dar pe măsură ce aplicația crește, poate mări considerabil volumul de date transferat la fiecare cerere și cantitatea de cod JavaScript necesară pentru procesare.

În loc să sortezi ultimele facturi în memorie (_in-memory_), poți folosi o interogare SQL pentru a prelua direct din baza de date doar ultimele 5 înregistrări.
Iată interogarea SQL din fișierul `data.ts`:

```typescript
// /app/lib/data.ts
// Preluarea ultimelor 5 facturi, sortate după dată
const data = await sql<LatestInvoiceRaw[]>`
  SELECT invoices.amount, customers.name, customers.image_url, customers.email
  FROM invoices
  JOIN customers ON invoices.customer_id = customers.id
  ORDER BY invoices.date DESC
  LIMIT 5`;
```

În pagina ta, importă funcția `fetchLatestInvoices`:

```tsx
// /app/dashboard/page.tsx
import { Card } from '@/app/ui/dashboard/cards';
import RevenueChart from '@/app/ui/dashboard/revenue-chart';
import LatestInvoices from '@/app/ui/dashboard/latest-invoices';
import { lusitana } from '@/app/ui/fonts';
import { fetchRevenue, fetchLatestInvoices } from '@/app/lib/data';

export default async function Page() {
  const revenue = await fetchRevenue();
  const latestInvoices = await fetchLatestInvoices();
  // ...
}
```

Apoi, decomentează componenta `<LatestInvoices/>`.
Va trebui, de asemenea, să decomentezi codul corespunzător din interiorul fișierului componentei, situat la `/app/ui/dashboard/latest-invoices.tsx`.

Dacă accesezi `localhost`, vei observa că sunt returnate doar ultimele 5 facturi din baza de date.
Cu siguranță începi să vezi avantajele interogării directe a bazei de date!
