## Utilizarea SQL

Pentru aplicația ta de tip dashboard, vei scrie interogări în baza de date folosind biblioteca `postgres.js` și SQL.
Există câteva motive pentru care vom folosi SQL:

- **SQL este standardul din industrie** pentru interogarea bazelor de date relaționale (de exemplu, ORM-urile generează tot SQL în fundal).
- **Înțelegerea noțiunilor de bază din SQL** te ajută să asimilezi fundamentele bazelor de date relaționale, permițându-ți să aplici aceste cunoștințe și cu alte instrumente.
- **SQL este versatil**, oferindu-ți flexibilitatea de a prelua și manipula date specifice.
- **Biblioteca `postgres.js` oferă protecție nativă împotriva atacurilor de tip SQL injection.**

Nu-ți face griji dacă nu ai mai folosit SQL până acum – interogările sunt deja pregătite pentru tine.

Mergi în fișierul `/app/lib/data.ts`. Acolo vei vedea cum este configurat `postgres`.
Funcția `sql` îți permite să execuți interogări în baza de date:

```typescript
// /app/lib/data.ts
import postgres from 'postgres';

const sql = postgres(process.env.POSTGRES_URL!, { ssl: 'require' });
// ...
```

Poți apela funcția `sql` oriunde pe server (de exemplu, direct într-un React Server Component).
Totuși, pentru o mai bună organizare și o navigare mai ușoară prin cod, toate interogările de date sunt centralizate în fișierul `data.ts`, de unde le poți importa în componente.
