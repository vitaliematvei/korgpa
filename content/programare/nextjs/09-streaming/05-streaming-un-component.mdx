Până acum, ai realizat streaming-ul unei pagini întregi.
Însă poți fi și mai granular și poți transmite prin streaming componente specifice folosind **React Suspense**.

`Suspense` îți permite să amâni randarea unor părți din aplicație până când o anumită condiție este îndeplinită (de exemplu, până când datele sunt încărcate).
Poți înfășura componentele dinamice în `Suspense`, oferindu-i o componentă de rezervă (_fallback component_) pe care să o afișeze în timp ce componenta dinamică se încarcă.

Dacă îți amintești cererea lentă de date `fetchRevenue()`, aceasta era cererea care încetinea întreaga pagină.
În loc să blochezi întreaga pagină, poți folosi `Suspense` pentru a transmite prin streaming doar această componentă și pentru a afișa imediat restul interfeței paginii.

Pentru a face asta, va trebui să muți preluarea datelor direct în interiorul componentei.
Hai să actualizăm codul pentru a vedea cum va arăta:

Șterge toate instanțele lui `fetchRevenue()` și datele aferente din `/app/dashboard/(overview)/page.tsx`:

```tsx
// /app/dashboard/(overview)/page.tsx
import { Card } from '@/app/ui/dashboard/cards';
import RevenueChart from '@/app/ui/dashboard/revenue-chart';
import LatestInvoices from '@/app/ui/dashboard/latest-invoices';
import { lusitana } from '@/app/ui/fonts';
import { fetchLatestInvoices, fetchCardData } from '@/app/lib/data'; // elimină fetchRevenue

export default async function Page() {
  // const revenue = await fetchRevenue() // șterge această linie
  const latestInvoices = await fetchLatestInvoices();
  const {
    numberOfInvoices,
    numberOfCustomers,
    totalPaidInvoices,
    totalPendingInvoices,
  } = await fetchCardData();

  return (
    // ...
  );
}

```

Apoi, importă `<Suspense>` din `react` și înfășoară componenta `<RevenueChart/>`.
Îi poți transmite o componentă de rezervă numită `<RevenueChartSkeleton>` în prop-ul `fallback`:

```tsx
// /app/dashboard/(overview)/page.tsx
import { Card } from '@/app/ui/dashboard/cards';
import RevenueChart from '@/app/ui/dashboard/revenue-chart';
import LatestInvoices from '@/app/ui/dashboard/latest-invoices';
import { lusitana } from '@/app/ui/fonts';
import { fetchLatestInvoices, fetchCardData } from '@/app/lib/data';
import { Suspense } from 'react';
import { RevenueChartSkeleton } from '@/app/ui/skeletons';

export default async function Page() {
  const latestInvoices = await fetchLatestInvoices();
  const {
    numberOfInvoices,
    numberOfCustomers,
    totalPaidInvoices,
    totalPendingInvoices,
  } = await fetchCardData();

  return (
    <main>
      <h1 className={`${lusitana.className} mb-4 text-xl md:text-2xl`}>
        Dashboard
      </h1>
      <div className="grid gap-6 sm:grid-cols-2 lg:grid-cols-4">
        <Card title="Collected" value={totalPaidInvoices} type="collected" />
        <Card title="Pending" value={totalPendingInvoices} type="pending" />
        <Card title="Total Invoices" value={numberOfInvoices} type="invoices" />
        <Card
          title="Total Customers"
          value={numberOfCustomers}
          type="customers"
        />
      </div>
      <div className="mt-6 grid grid-cols-1 gap-6 md:grid-cols-4 lg:grid-cols-8">
        <Suspense fallback={<RevenueChartSkeleton />}>
          <RevenueChart />
        </Suspense>
        <LatestInvoices latestInvoices={latestInvoices} />
      </div>
    </main>
  );
}
```

În cele din urmă, actualizează componenta `<RevenueChart>` astfel încât să își preia singură datele și elimină prop-ul care îi era transmis:

```tsx

```

Acum reîmprospătează pagina și ar trebui să vezi informațiile principale din dashboard aproape imediat,
în timp ce un skeleton de rezervă este afișat pentru `<RevenueChart>`.
