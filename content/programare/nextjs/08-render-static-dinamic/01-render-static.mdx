---
title: 'Ce este Rendarea Statică? (Static Rendering)'
description: 'Ce este Rendarea Statică? (Static Rendering)'
order: 1
category: 'NextJS'
level: 'Incepator'
---

În cazul rendării statice, preluarea datelor și randarea au loc pe server la **momentul construirii aplicației** (_build time_, când faci deploy) sau în timpul **revalidării datelor**.

Ori de câte ori un utilizator îți vizitează aplicația, îi este livrat rezultatul deja salvat în cache.
Rendarea statică oferă o serie de avantaje majore:

- **Site-uri web mai rapide** — Conținutul pre-randat poate fi salvat în cache și distribuit global atunci când este lansat pe platforme precum Vercel.
  Acest lucru garantează că utilizatorii din întreaga lume pot accesa conținutul mai rapid și mai fiabil.
- **Sarcina redusă a serverului** — Deoarece conținutul este stocat în cache, serverul nu trebuie să genereze dinamic conținut la fiecare cerere a unui utilizator.
  Acest lucru reduce costurile de calcul (_compute costs_).
- **SEO îmbunătățit** — Conținutul pre-randat este mult mai ușor de indexat de către motoarele de căutare (_crawlers_), deoarece conținutul este deja disponibil în momentul în care pagina se încarcă.
  Asta poate duce la o poziționare mai bună în rezultatele căutărilor.

Rendarea statică este extrem de utilă pentru interfețe fără date dinamice sau unde datele sunt identice pentru toți utilizatorii (cum ar fi un articol de blog static sau o pagină de prezentare a unui produs).
Totuși, **nu este potrivită pentru un panou de control (dashboard)** care afișează date personalizate și actualizate frecvent.

Opusul rendării statice este **rendarea dinamică** (_dynamic rendering_).
