# Puterea subconstientului

Creierul uman este unul dintre cele mai eficiente "procesoare" pe care le cunoastem.
Desi are dimensiunea aproximativa a unui grapefruit mare si consuma energie comparabila
cu un bec economic, performanta lui este uriasa. Comparat cu unele dintre cele mai
puternice supercomputere, creierul ramane remarcabil prin viteza si eficienta.

Intrebarea importanta este: cum se imparte aceasta capacitate intre mintea constienta si
cea inconstienta?

In practica, mintea inconstienta este partea mai puternica. Exista cateva motive cheie:

- Rationamentul constient se desfasoara de obicei in forma verbala, iar viteza "vocii
  interioare" este limitata.
- Gandirea constienta apare printr-un schimb continuu cu procesele inconstiente;
  fiecare ciclu consuma timp.
- Daca e nevoie si de feedback din mediul exterior, apare un timp suplimentar de
  asteptare pana cand informatia ajunge in constiinta.
- Mintea constienta poate urmari eficient un singur fir principal odata, in timp ce
  procesele inconstiente ruleaza simultan, in paralel.

Mintea inconstienta poate realiza performante impresionante. De exemplu, cat dureaza
rezolvarea unui cub Rubik?

Pentru cineva fara experienta, care urmeaza pasii in mod strict constient, rezolvarea poate
dura in jur de 5 minute chiar si cu instructiunile in fata. Recordurile mondiale sunt sub
5 secunde. Cum este posibil?

Practicantii de nivel inalt repeta pana cand regulile se fixeaza in inconstient, asemanator
cu regulile gramaticale pe care vorbitorii nativi le folosesc fara sa le "calculeze" constient.
Algoritmii devin familiari, miscarile devin reflexe, iar executia este sustinuta de memoria
musculara. Constiinta ramane in principal ocupata cu anticiparea pasului urmator.

Acelasi fenomen apare si la sahisti. Chiar daca folosesc constient strategii si euristici,
o mare parte din joc se bazeaza pe un "simt" inconstient al tablei. Daca incerci sa analizezi
strict constient toate combinatiile posibile, volumul de variante devine urias foarte repede.

Un alt exemplu este abacul mental, practicat intens in Japonia. Participantii pot aduna
rapid serii de numere afisate pentru foarte scurt timp. Chiar daca nu pot reda toate numerele
din memorie imediat dupa, raspunsul final este adesea corect.

Toate aceste abilitati, si multe altele, nu ar fi posibile fara puterea inconstientului si fara
mii de ore de practica. Maestrii la cub Rubik, sah sau abac mental se antreneaza ani la rand,
adesea cateva ore pe zi.

In literatura de mixaj vei gasi multe retete: "fa asta", "foloseste asta". Retetele sunt utile,
dar ele sunt executate in primul rand de mintea constienta. Iar gandirea constienta ramane
importanta in mixaj: fiecare inginer are proceduri, tehnici si argumente.

Totusi, spre deosebire de un set fix de pasi pentru o problema bine definita, in mixaj nu
exista o formula garantata care sa produca mereu un mix excelent. O parte mare din
calitatea deciziilor vine din inconstient, adevarata forta a creierului.

Vestea buna este ca accesarea acestei forte este simpla:

Mixeaza.
