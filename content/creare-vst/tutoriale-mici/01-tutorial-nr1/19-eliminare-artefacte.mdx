În tutorialul **„Juce Tutorial 18 - Using a Gain Ramp to Eliminate Sound Artifacts”** de pe canalul _The Audio Programmer_, autorul explică cum se elimină zgomotele sau clicurile nedorite (_artifacts_ / _clicks_) atunci când schimbi rapid volumul (_gain_) într-un plugin realizat în cadrul framework-ului JUCE (C++).

Sursa problemei o constituie schimbarea instantanee a amplitudinii semnalului audio de la o mostră (_sample_) la alta. Soluția constă în **interpolarea lină** (_gain ramp_) pe parcursul unui bloc de cadre audio (_buffer_).

---

### Soluția pas cu pas

1. **1. Declararea variabilei stării anterioare:** În fișierul de antet PluginProcessor.h.
   Trebuie să păstrezi valoarea nivelului audio din cadrul procesării anterioare.

Adaugă o variabilă de tip `float` în secțiunea privată a clasei audio processor:

```cpp
private:
    float previousGain;

```

2. **2. Inițializarea în metoda prepareToPlay():** În fișierul PluginProcessor.cpp.
   Înainte de procesarea propriu-zisă a semnalului, inițializează `previousGain` cu valoarea curentă a parametrului din procesor (și nu direct din GUI Editor, pentru a preveni erorile de stare când interfața grafică este închisă).

```cpp
void YourAudioProcessor::prepareToPlay (double sampleRate, int samplesPerBlock)
{
    // Preluăm valoarea brută din parametru și o transformăm din dB în coeficient liniar (0.0 - 1.0)
    auto rawGain = *parameters.getRawParameterValue ("gainID");
    previousGain = std::pow (10.0f, rawGain / 20.0f);
}

```

3. **3. Obținerea gain-ului curent în processBlock():** În fișierul PluginProcessor.cpp.
   În cadrul metodei de procesare audio în timp real (`processBlock`), citește valoarea nouă cerută de utilizator la fiecare cadru/bloc audio:

```cpp
void YourAudioProcessor::processBlock (juce::AudioBuffer<float>& buffer, juce::MidiBuffer& midiMessages)
{
    juce::ScopedNoDenormals noDenormals;
    buffer.clear(); // Sau curățarea canalelor neutilizate

    // Calculăm câștigul curent dorit
    auto rawGain = *parameters.getRawParameterValue ("gainID");
    float currentGain = std::pow (10.0f, rawGain / 20.0f);

    // ... continuă la pasul următor

```

4. **4. Aplicarea rampa de gain (Gain Ramp):** Alegerea metodei în funcție de schimbarea parametrului.
   În loc să folosești o buclă `for` imbricată peste fiecare mostră audio, poți folosi metodele optimizate puse la dispoziție de clasa `juce::AudioBuffer`:

- Dacă valoarea nu s-a schimbat (`currentGain == previousGain`), se aplică un volum constant pe întregul buffer.
- Dacă valoarea s-a schimbat, se folosește `applyGainRamp` pentru o tranziție lină pe numărul total de cadre audio din buffer (ex. 512 mostre).

```cpp
    // Dacă volumul este constant, aplicăm volum direct
    if (currentGain == previousGain)
    {
        buffer.applyGain (currentGain);
    }
    else
    {
        // Aplică o rampă lină de la previousGain la currentGain
        // Parametrii: (startSample, numSamples, startGain, endGain)
        buffer.applyGainRamp (0, buffer.getNumSamples(), previousGain, currentGain);

        // Actualizăm valoarea anterioară cu cea curentă pentru următorul bloc
        previousGain = currentGain;
    }
}

```
