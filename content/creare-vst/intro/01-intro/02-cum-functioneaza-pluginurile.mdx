Materialul acesta este despre crearea de plug-in-uri audio.

## Așadar, ce este mai exact un plug-in?

În ziua de azi, majoritatea melodiilor sunt înregistrate și editate cu ajutorul unui program de tip DAW (Digital Audio Workstation) sau stație de lucru audio digitală.
Câteva exemple cunoscute sunt: Logic Pro, Ableton Live, REAPER, Cubase, FL Studio, GarageBand, Bitwig Studio, Pro Tools și multe altele.

Programele DAW vin deja la pachet cu o mulțime de funcții integrate, dar le permit și altor dezvoltatori independenți să adauge funcționalități noi prin intermediul plug-in-urilor.

# Un plug-in

este o extensie software care se încarcă într-un alt program principal, numit gazdă (host), pentru a-i extinde capacitățile.

În cazul plug-in-urilor audio, gazda este de obicei un DAW, dar poate fi, de exemplu, și un program de editare video.

# Un plug-in audio

este adesea numit simplu VST, după numele tehnologiei care a făcut posibilă existența lor pentru prima dată: Virtual Studio Technology, creată de compania Steinberg.

În majoritatea programelor DAW, plug-in-ul este plasat pe o pistă (track) din proiectul utilizatorului, fiind astfel integrat direct în lanțul de procesare audio al acelei piste.
Se pot adăuga mai multe plug-in-uri pe o singură pistă.
Fiecare dintre ele va citi semnalul audio care intră și îl va modifica într-un anumit fel.
