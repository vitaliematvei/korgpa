# Programarea functiei Style to KBD Set

Poti programa modul in care functioneaza butonul **STYLE TO KBD SET**.

1. Mergi la **Global > Mode Preferences > Style 1**.

<figure className="my-6 text-center">
  <img
    src="/images/redare-style/style-to-keyboard.jpg"
    alt="Pagina de programare Style to Keyboard Set pe KORG Pa4X"
    className="mx-auto"
  />
</figure>

2. Foloseste meniul **Style to Kbd Set Mode** pentru a alege cum functioneaza butonul.

  <thead className="bg-slate-300 text-left">

        Mod Style to Kbd Set
      </th>

        Semnificatie
      </th>
    </tr>
  </thead>
  <tbody>
    <tr className="odd:bg-white even:bg-slate-100">
      <td className="border-2 border-slate-500 px-4 py-2 align-top font-semibold">
        Next Measure
      </td>
      <td className="border-2 border-slate-500 px-4 py-2">
        Cand alegi un Style, noul Keyboard Set va fi selectat automat abia la
        prima bataie a urmatoarei masuri.
      </td>
    </tr>
    <tr className="odd:bg-white even:bg-slate-100">
      <td className="border-2 border-slate-500 px-4 py-2 align-top font-semibold">

      </td>

        Cand alegi un Style, noul Keyboard Set este selectat imediat.
      </td>
    </tr>
  </tbody>
</table>

3. Apasa butonul **EXIT** pentru a reveni la pagina anterioara.
