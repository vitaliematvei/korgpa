# Repetarea (Loop) secțiunilor

Dacă simți că o secțiune Intro, Fill, Break sau Ending ar trebui să dureze mai mult decât modelul înregistrat, o poți pune pe repeat (loop).

## Setarea unui Element Style pe loop

▪▪ Apasă de două ori butonul Intro, Fill, Break sau Ending pentru a-l pune pe loop. Indicatorul de pe buton va începe să clipească, iar modelul va începe să se repete.

## Ieșirea din loop

Fă una dintre următoarele:

▪▪ Apasă din nou același buton de Element Style, sau
▪▪ Selectează un alt Element Style.

## Ținerea unui Element Style pe loop cât timp butonul este apăsat

▪▪ Ține apăsat butonul Intro, Fill, Break sau Ending pentru a-l menține pe loop. Eliberează-l când vrei ca secțiunea să iasă din loop.

▪▪ Dacă funcția Auto Fill este activată, ține apăsat butonul Variation pentru a repeta Fill-ul corespunzător. Eliberează-l când vrei ca Fill-ul să iasă din loop și să înceapă Variation-ul.
