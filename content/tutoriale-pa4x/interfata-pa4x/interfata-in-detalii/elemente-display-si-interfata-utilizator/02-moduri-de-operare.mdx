# Moduri de operare

Paginile Pa4X sunt grupate in diferite moduri de operare.

Fiecare mod este accesat prin apasarea butonului corespunzator din sectiunea

<span className="font-bold">MODE</span> de pe panoul de control.

<figure className="my-6 text-center">
  <img
    src="/images/inerfata-principala/moduri-operative.jpg"
    alt="Moduri de operare pe KORG Pa4X"
    className="mx-auto"
  />
</figure>

Fiecare mod de operare este marcat cu un cod de culoare diferit, pentru a
intelege rapid unde te afli.

Doua moduri speciale, <span className="font-bold">Global</span> si <span className="font-bold">Media</span>, se suprapun peste modul curent, care
ramane activ in fundal.

Modul <span className="font-bold">Record</span> poate fi accesat din:

1. <span className="font-bold">Style Play</span>
2. <span className="font-bold">Sequencer</span>
3. <span className="font-bold">Sound</span>

In acest mod, poti crea:

1. <span className="font-bold">Style</span>-uri
2. <span className="font-bold">Pad</span>-uri
3. <span className="font-bold">Song</span>-uri
4. <span className="font-bold">Sample</span>-uri noi.
