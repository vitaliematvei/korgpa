# Casete de dialog

Similar cu ferestrele de selectie, casetele de dialog se suprapun peste pagina
curenta.

Atinge unul dintre butoanele afisate pe ecran pentru a oferi un raspuns
instrumentului Pa4X, iar caseta de dialog se va inchide automat.
