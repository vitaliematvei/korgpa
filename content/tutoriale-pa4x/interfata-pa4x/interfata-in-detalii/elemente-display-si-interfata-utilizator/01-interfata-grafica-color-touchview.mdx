# Interfata grafica Color TouchView

Pa4X include interfata grafica exclusiva si usor de utilizat

<span className="font-bold">TouchView</span>, bazata pe un ecran LCD cu panou
tactil.

Prin atingerea elementelor afisate pe ecranul LCD, poti selecta pagini, file
si parametri, iar valorile parametrilor pot fi setate din meniurile si
butoanele afisate direct pe ecran.
