# Ferestre suprapuse

Mai multe ferestre, cum ar fi <span className="font-bold">Style Select</span>,

<span className="font-bold">Sound Select</span>,
<span className="font-bold">Global</span>,
<span className="font-bold">Media</span> sau
<span className="font-bold">Lyrics</span>, se suprapun peste fereastra curenta.

Dupa ce selectezi un element din fereastra sau apesi butonul

<span className="font-bold">EXIT</span>, fereastra se inchide si pagina
anterioara este afisata din nou.
