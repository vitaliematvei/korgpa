# Deschiderea unei ferestre Select

Cand apesi unul dintre butoanele <span className="font-bold">STYLE</span>, <span className="font-bold">SOUND SELECT</span> sau unul dintre butoanele

<span className="font-bold">KEYBOARD SET LIBRARY</span>, apare fereastra Select
corespunzatoare.

De exemplu, aceasta este fereastra <span className="font-bold">Sound Select</span>:

<figure className="my-6 text-center">
  <img
    src="/images/inerfata-principala/select-window.jpg"
    alt="Fereastra Sound Select"
    className="mx-auto"
  />
</figure>

Fereastra Select poate fi deschisa si daca atingi numele elementului
corespunzator afisat pe ecran.

Poti iesi oricand din aceasta fereastra apasand butonul <span className="font-bold">EXIT</span>.

Pe Pa4X, ferestrele Select raman deschise pana cand apesi butonul <span className="font-bold">EXIT</span>. Daca preferi sa se inchida automat dupa
cateva secunde sau dupa ce selectezi ceva, dezactiveaza parametrul <span className="font-bold">Display Hold</span>.
