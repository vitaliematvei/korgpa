# Sounds (și Set Lists) area

Sunetele sunt ceea ce poți cânta la claviatură. Aici poți alege seturi de sunete salvate ca Keyboard Sets într-o bibliotecă dedicată. De asemenea, poți selecta Set Lists din SongBook, care sunt colecții de seturi de sunete asociate cu un anumit Stil sau Cântec.
