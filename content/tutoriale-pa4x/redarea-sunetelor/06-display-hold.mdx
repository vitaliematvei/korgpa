# Display Hold

Este posibil sa preferi sa lasi o fereastra Select deschisa dupa ce ai ales
un Sound, un Keyboard Set sau un Style, ca sa poti incerca si alte elemente
in acea fereastra. Sau poate preferi ca fereastra sa se inchida automat dupa
ce ai terminat selectia. Acest comportament este stabilit de parametrul

<span className="font-bold">Display Hold</span>.

## Activarea sau dezactivarea parametrului Display Hold

1. Mergi la pagina <span className="font-bold">Global > General Controls > Interface</span>.
2. Activeaza sau dezactiveaza parametrul <span className="font-bold">Display Hold</span>:
   - Selecteaza checkbox-ul <span className="font-bold">Display Hold On</span>
     pentru a-l activa. Ferestrele Select pentru Sound, Keyboard Set, Style,
     Pad sau Voice Preset vor ramane deschise pe display pana cand apesi
     butonul <span className="font-bold">EXIT</span>.
   - Deselecteaza checkbox-ul <span className="font-bold">Display Hold On</span>
     pentru a-l dezactiva. Ferestrele Select pentru Sound, Keyboard Set,
     Style, Pad sau Voice Preset se vor inchide automat dupa ce alegi un
     element.
3. Apasa butonul <span className="font-bold">EXIT</span> pentru a reveni la
   pagina anterioara.
