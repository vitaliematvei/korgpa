In fiecare Style sau SongBook Entry exista patru Keyboard Seturi de claviatura
corespunzatoare, ajustate fin pentru Style-ul sau intrarea SongBook in care
se afla. Le poti alege din panoul de control sau direct de pe display.

## Alegerea unui Set de claviatura din panoul de control

- Apasa unul dintre butoanele din sectiunea
  <span className="font-bold">KEYBOARD SET</span> aflata sub display.

</figure>

## Selectarea unui Set de claviatura din display

1. In pagina Main, asigura-te ca panoul <span className="font-bold">Kbd Set</span>
   este selectat. Daca nu este selectat, atinge tab-ul
   <span className="font-bold">Kbd Set</span> pentru a-l selecta.

<figure className="my-6 text-center">
  <img
    src="/images/redare-sunete/STS-display.jpg"
    alt="Panoul Kbd Set selectat in pagina Main"
    className="mx-auto"
  />
</figure>

2. Atinge unul dintre numele Keyboard Set afisate pe display pentru a-l
   selecta.

Vei vedea numele Keyboard Set-ului selectat evidentiat in zona dedicata din
pagina Main. Sunetele atribuite claviaturii (afisate in jumatatea dreapta a
display-ului) se vor schimba.
