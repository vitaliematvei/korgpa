My Setting este un Set de claviatura special, in care poti salva setarile
preferate pentru elemente precum sunetele de claviatura, efectele,
comutatoarele asignabile si un Style care sa fie selectat la pornire.

Acest Set de claviatura este ales automat cand instrumentul este pornit si
configureaza automat instrumentul pentru tine.

## Salvarea Setului de claviatura My Setting

Tine apasat butonul <span className="font-bold">MY SETTING</span> timp de
aproximativ o secunda, pana apare dialogul Write, apoi atinge butonul

<span className="font-bold">OK</span> pentru a confirma salvarea in memorie.
