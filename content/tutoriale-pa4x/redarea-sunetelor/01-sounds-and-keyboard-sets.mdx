# Sunete si Seturi de claviatura

Sunetele sunt elementul de baza a ceea ce auzi de la instrumentul tau.
Pa4X contine sunete din orice familie instrumentala (piane, corzi,
sintetizatoare etc.). Un set de sunete care canta impreuna pe claviatura
poate fi memorat ca un **Set de claviatura**.

Pentru a reapela automat sunetele si setarile, de obicei selectezi un
**Set de claviatura**. Un Set de claviatura este o singura locatie de
memorie care poate retine sunetele de pe claviatura si toate setarile lor
de transpunere, efecte etc.

Seturile de claviatura sunt stocate individual in Keyboard Set Library
(butoanele KEYBOARD SET LIBRARY). Acestea sunt asociate si cu un Style
sau cu o intrare SongBook; un grup de patru Seturi de claviatura este
reapelat de fiecare data cand selectezi un Style sau o intrare SongBook
(butoanele KEYBOARD SET de sub display).

<figure className="my-6 text-center">
  <img
    src="/images/redare-sunete/keyboard-set2.jpg"

    className="mx-auto"

</figure>

La alegerea unui Style, Setul de claviatura reapelat automat depinde de
starea butonului STYLE TO KBD SET. La alegerea unei intrari SongBook, este reapelat intotdeauna Setul de claviatura #1.
