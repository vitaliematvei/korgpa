Seturile de claviatura sunt stocate intr-o librarie dedicata, pe care o poti
accesa din panoul de control sau direct de pe display.

## Deschiderea ferestrei Keyboard Set Select din panoul de control

1. Asigura-te ca indicatorul <span className="font-bold">SET LIST</span> este oprit.
2. Apasa unul dintre butoanele din sectiunea <span className="font-bold">KEYBOARD SET LIBRARY</span>. Vei observa ca fiecare dintre ele are imprimat deasupra numele unei familii de instrumente.
   <figure className="my-6 text-center">
     <img
       src="/images/redare-sunete/set-list.jpg"
       alt="Indicatorul SET LIST pe KORG Pa4X"
       className="mx-auto"
     />
   </figure>

## Deschiderea ferestrei Keyboard Set Select din display

- In pagina Main, atinge numele Keyboard Setului de claviatura selectat.

<figure className="my-6 text-center">
  <img
    src="/images/redare-sunete/select-keyboard-set.jpg"
    alt="Fereastra Select Keyboard Set pe KORG Pa4X"
    className="mx-auto"
  />

Keyboard Set Select.

2. **Daca vrei sa alegi** un grup diferit de Keyboard Seturi de claviatura, fie apasa un alt
   buton din sectiunea <span className="font-bold">KEYBOARD SET LIBRARY</span>, fie
   atinge una dintre tab-urile aflate pe lateralele ferestrei Keyboard Set Library
   Select.

<figure className="my-6 text-center">
  <img
    src="/images/redare-sunete/select-KBS-window.jpg"
    alt="Selectarea grupului in fereastra Keyboard Set Library Select"
    className="mx-auto"
  />
</figure>

3. Pentru a alege una dintre paginile disponibile din grupul selectat de Seturi
   de claviatura, fie atinge unul dintre tab-urile P1...P6 din partea de jos a
   ferestrei, fie apasa in mod repetat butonul grupului selectat de Seturi de
   claviatura din sectiunea <span className="font-bold">KEYBOARD SET LIBRARY</span>
   a panoului de control.

<figure className="my-6 text-center">
  <img
    src="/images/redare-sunete/selectare-pagini-KBS.jpg"
    alt="Selectarea paginilor P1-P6 pentru Keyboard Set"
    className="mx-auto"
  />
</figure>

4. Atinge numele Keyboard Set-ului pe care vrei sa il selectezi.

<figure className="my-6 text-center">
  <img
    src="/images/redare-sunete/KBS-name.jpg"
    alt="Selectarea numelui Keyboard Set in fereastra"
    className="mx-auto"
  />
</figure>

5. Daca vrei sa inchizi fereastra Keyboard Set Library Select (si aceasta nu
   se inchide automat), apasa butonul EXIT.

La final, vei vedea numele Keyboard Set-ului selectat in zona dedicata din
pagina Main. Sunetele asignate claviaturii (afisate in jumatatea dreapta a
display-ului) se vor schimba.
