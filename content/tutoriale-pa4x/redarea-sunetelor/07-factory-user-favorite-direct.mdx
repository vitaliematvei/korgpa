# Factory, User, Favorite, Direct

Pe diferite pagini vei intalni termeni precum Factory, User, Favorite si
Direct. Acesti termeni se refera la nivelul de protectie la scriere sau la
cat de mult pot fi personalizate resursele.

- <span className="font-bold">Factory (si Local)</span> (Keyboard Sets, Sounds,
  Styles, Pads, Voice Presets) sunt elemente pe care, in mod normal, nu le poti
  suprascrie sau modifica. Scopul lor este sa garanteze ca resursele muzicale
  (de exemplu intrarile SongBook) vor gasi mereu resursele legate (de exemplu
  Style-urile).
- <span className="font-bold">User</span> (Keyboard Sets, Sounds, Styles, Pads,
  Voice Presets) sunt elemente pe care le poti scrie, modifica sau suprascrie.
  Bancile User pentru Keyboard Set si Pad (tab-urile laterale) pot fi redenumite
  pentru a crea propriile categorii.
- <span className="font-bold">Favorite</span> (Styles) sunt elemente de tip
  User, in care poti pune o selectie de elemente preferate. Poti redenumi liber
  aceste banci (tab-urile laterale) pentru a crea propriile categorii.
- <span className="font-bold">Direct</span> (Keyboard Sets, Styles, Pads,
  SongBook Entries, Voice Presets) sunt elemente User/Favorite pe care le poti
  accesa direct de pe un dispozitiv de stocare.
