## Ce este un fișier MIDI

Denumirea tehnică pentru un „MIDI Song” este Standard MIDI File, prescurtat adesea SMF.

Extensia fișierului este `.mid`. Standard MIDI File reprezintă formatul standard din industrie pentru melodii și este folosit de Pa4X ca format nativ pentru redarea sau înregistrarea melodiilor MIDI.

Fișierul MIDI Karaoke (`.kar`) este o extensie a formatului SMF și este de asemenea suportat. Acesta conține întotdeauna versuri.
