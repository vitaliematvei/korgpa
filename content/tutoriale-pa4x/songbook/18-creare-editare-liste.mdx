#### Activarea editării listelor (Set List)

Pentru a preveni modificările accidentale, opțiunea de editare a listelor Set List este dezactivată în mod implicit.

**Pentru a activa editarea Set List:**

- În fereastra **SongBook**, deschideți meniul paginii (colțul din dreapta sus) și selectați opțiunea **Enable Set List Edit**.
- Dacă doriți să protejați din nou listele după finalizarea modificărilor, debifați opțiunea **Enable Set List Edit** din același meniu.

Când editarea este activată, în partea de jos a paginii va apărea un set nou de butoane dedicate configurării.
