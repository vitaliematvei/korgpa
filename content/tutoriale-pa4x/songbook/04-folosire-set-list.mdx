# Ce sunt Set List-urile?

Set List-urile sunt selecții personalizate din lista completă Book. Ele permit crearea unor liste mai mici, adaptate pentru un anumit eveniment sau pentru preferințele tale muzicale.

Am inclus deja câteva exemple de Set List-uri, pe care le poți folosi la propriile concerte sau spectacole.

## Vizualizare Set List: Tile View vs. List View

Set List-urile pot fi afișate fie în modul **Tile View** (vizualizare pe plăcuțe), fie în **List View** (vizualizare listă simplă).

- În **Tile View**, melodiile sunt afișate sub formă de plăcuțe (tiles), pe pagini, și pot fi asociate butoanelor SET LIST de pe panoul de control.
- În **List View**, toate melodiile sunt afișate într-o listă simplă, ușor de derulat.

### Cum schimbi modul de vizualizare

1. În orice pagină SongBook, accesează meniul **Preferences** din meniul paginii pentru a deschide dialogul de preferințe.

## Redarea unui Set List din Tile View

În modul **Tile View**, Set List-ul selectat este afișat ca o serie de melodii asociate butoanelor SET LIST de pe panoul de control. Fiecare plăcuță (tile) din ecran corespunde aceluiași buton numerotat.

### Selectarea unui Set List

1. Accesează pagina **SongBook > Set List**. Poți apăsa direct butonul **SET LIST** pentru a deschide această pagină.
2. Asigură-te că ești în modul **Tile View**. Dacă nu, accesează meniul **Preferences** din meniul paginii pentru a deschide dialogul de preferințe și selectează modul Tile View.

3. Asigură-te că ești în modul **Tile View**. Dacă nu, accesează meniul **Preferences** din meniul paginii pentru a deschide dialogul de preferințe și selectează modul Tile View.

## Redarea și navigarea în Set List

### Selectarea unei melodii din Set List

1. Asigură-te că te afli în pagina **SongBook > Set List**.
2. Atinge una dintre plăcuțele (tiles) din ecran pentru a selecta melodia dorită.

### Redarea și controlul melodiilor din Set List

1. Folosește butonul **START/STOP** sau **PLAY/STOP** pentru a porni sau opri redarea stilului sau melodiei selectate.
2. Utilizează comenzile standard **Arranger** sau **Player** pentru a porni, întrerupe, opri, derula înainte sau înapoi stilurile sau melodiile.
3. Treci la melodia anterioară sau următoare folosind butoanele **Prev** (Previous) sau **Next**.

## Redarea unui Set List din List View

În modul **List View**, Set List-ul selectat este afișat ca o listă simplă de melodii.

### Selectarea unui Set List în List View

1. Apasă butonul **SET LIST** pentru a deschide pagina **SongBook > Set List**.
2. Asigură-te că ești în modul **List View**. Dacă nu, accesează meniul **Preferences** și selectează modul List View.
3. Selectează Set List-ul dorit din lista disponibilă.

### Redarea și controlul melodiilor în List View

1. Atinge melodia dorită din listă pentru a o selecta.
2. Folosește butonul **START/STOP** sau **PLAY/STOP** pentru a porni sau opri redarea.
3. Utilizează comenzile **Arranger** sau **Player** pentru control avansat (pauză, derulare, etc.).
4. Poți naviga rapid la orice melodie din listă printr-o simplă atingere.

### Pași pentru redarea și navigarea în List View

1. Folosește meniul pop-up **List** pentru a selecta unul dintre Set List-urile disponibile.
2. Lista melodiilor din Set List-ul selectat va apărea pe ecran. (Spre deosebire de modul Tile View, melodiile NU sunt asociate butoanelor SET LIST de pe panoul de control.)
3. Parcurge lista de melodii și atinge numele melodiei de la care vrei să înceapă redarea, pentru a o asocia Arranger-ului sau Player-ului.
4. Folosește butonul **START/STOP** sau **PLAY/STOP** pentru a porni sau opri redarea stilului sau melodiei selectate.
5. Utilizează comenzile standard **Arranger** sau **Player** pentru a porni, întrerupe, opri, derula înainte sau înapoi stilurile sau melodiile.
6. Treci la melodia anterioară sau următoare folosind butoanele **Prev** (Previous) sau **Next**.
7. Poți selecta orice altă melodie atingând o altă intrare din listă.
