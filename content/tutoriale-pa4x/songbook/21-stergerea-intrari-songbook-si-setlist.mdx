description: Ștergerea tuturor intrărilor din SongBook și a listelor Set List
category: Songbook
---

Este posibil să vrei să-ți creezi propria listă de melodii, eliminând toate intrările (Entries) și listele Set List implicite.

1. Mergi pe oricare dintre paginile meniului **SongBook**.
2. Selectează comanda **Initialize SongBook** din meniul paginii (colțul din dreapta-sus) și confirmă.

_Atenție: Această operațiune va șterge definitiv toate intrările (Entries) și listele Set List.
Pentru a reveni la datele originale din fabrică, folosește funcția **Factory Restore**._
