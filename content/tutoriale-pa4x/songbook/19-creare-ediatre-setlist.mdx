#### Crearea unei liste Set List noi, goale

1. Mergeți la pagina **SongBook > Set List**, apoi apăsați butonul **New List**.
2. Dacă a fost selectat un _Direct SongBook_, vi se va cere să alegeți între **Internal** și **Direct SongBook**. Alegeți o opțiune și apăsați **OK** pentru a confirma.
   _Listele Internal Set List vor folosi intrări interne (Internal Entries), în timp ce listele Direct Set List vor folosi doar intrări directe (Direct Entries). În acest fel, lista va găsi întotdeauna piesele asociate._
   Noua listă va fi selectată automat.

#### Selectarea unei liste Set List pentru editare

1. Mergeți la pagina **SongBook > Set List**. Alegeți modul de afișare **List View** sau **Tile View**.
2. Folosiți meniul pop-up **List** pentru a selecta lista _Set List_ pe care doriți să o editați.

### Adăugarea pieselor în lista Set List selectată

    1. Mergeți la pagina SongBook > Book.

    2. Parcurgeți lista de piese din baza de date SongBook.

    3. Când găsiți piesa căutată, apăsați pe ea. Dacă doriți să selectați mai multe piese deodată, țineți apăsat butonul SHIFT și selectați piesele dorite.

<figure className="my-6 text-center">
  <img src="/images/songbook/136-2.jpg" alt="" className="mx-auto" />
  <figcaption>Adăugarea pieselor în lista Set List selectată</figcaption>
</figure>

4. Apăsați butonul Add to list pentru a adăuga piesa (sau piesele) selectată(e) în
   lista Set List aleasă.

### Mutarea sau ștergerea pieselor din lista Set List selectată

1.  Mergeți la pagina **SongBook > Set List** și apăsați pe piesa pe care doriți să o mutați sau să o eliminați din listă.
    <figure className="my-6 text-center">
      <img src="/images/songbook/137-1.jpg" alt="" className="mx-auto" />
      <figcaption>
        Mutarea sau ștergerea pieselor din lista Set List selectată
      </figcaption>
    </figure>
2.  Editați lista.

        Folosiți butoanele Move > Down ( <img src="/images/songbook/137-2.jpg" alt="" className="inline" /> ) și Move > Up (<img src="/images/songbook/137-3.jpg" alt="" className="inline" /> ) de pe ecran pentru a muta piesa selectată pe o altă poziție în listă.

        Apăsați butonul Del Song pentru a șterge piesa selectată din lista Set List (piesa nu va fi însă ștearsă din baza de date Book).

### Salvarea listei Set List

    1. În timp ce vă aflați în pagina SongBook > Set List, apăsați butonul Write pentru a deschide fereastra de dialog Write List.

<figure className="my-6 text-center">
  <img src="/images/songbook/137-4.jpg" alt="" className="mx-auto" />
  <figcaption>Salvarea listei Set List</figcaption>
</figure>
2. În fereastra Write List, apăsați pictograma Text Edit (
<img src="/images/songbook/137-5.jpg" alt="" className="inline" /> ) dacă doriți
să atribuiți un nume nou listei Set List. Când ați terminat de editat numele,
confirmați apăsând butonul OK de sub tastatura virtuală.

3. Alegeți opțiunea Rename/Overwrite pentru a suprascrie lista Set List selectată. Dacă preferați să creați o listă nouă, alegeți în schimb opțiunea New List.

4. Apăsați butonul OK pentru a confirma salvarea.
