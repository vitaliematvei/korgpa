Cu fiecare intrare din SongBook se salvează o referință către o presetare de voce (_Voice Preset_). Când editezi o intrare, o poți înlocui.

1. **Selectează intrarea din SongBook** pe care dorești să o editezi și apasă butonul **EXIT** pentru a ieși din SongBook.
2. **Merg la panoul `Style Play`/`Song Play` > `Mic**` și alege o presetare de voce (_Voice Preset_). Bifează caseta **Global** dacă dorești să folosești presetarea globală.
3. **Merg la pagina `SongBook` > `Write**`. Vei observa că presetarea de voce a fost înlocuită.

<figure className="my-6 text-center">
  <img src="/images/songbook/130-1.jpg" alt="" className="mx-auto" />
  <figcaption>Salvarea unei alte presetări de voce (Voice Preset)</figcaption>
</figure>

4. Select the Voice Preset > Write checkbox to save the new Keyboard Sets
   instead of the older ones.
5. If you don’t want to replace the Style or Song, or the Keyboard Sets, be sure
   the other Write checkboxes are not selected.
6. Touch the Write button to save over the existing SongBook Entry.
