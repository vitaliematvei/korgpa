**Scrierea Seturilor de Sunete în bibliotecă**

Seturile de Sunete pot stoca sunetele de la tastatură (Keyboard Sounds) și setările aferente.
În bibliotecă le puteți organiza după tip și familie. Puteți accesa (rechema) aceste Seturi de Sunete folosind butoanele **KEYBOARD SET LIBRARY**.

_Notă: Toate modificările vor fi pierdute atunci când selectați un alt Set de Sunete, cu excepția cazului în care le salvați (scrieți).
În mod normal, modificările pot fi salvate doar în seturile de tip User sau Direct._

#### Scrierea unui Set de Sunete

**Deschiderea ferestrei de dialog „Write Keyboard Set to Library” din panoul de control**

- În modul Style Play sau Song Play, țineți apăsat oricare dintre butoanele **KEYBOARD SET LIBRARY** timp de aproximativ o secundă.

**Deschiderea ferestrei de dialog „Write Keyboard Set to Library” de pe ecran (display)**

- În modul Style Play sau Song Play, alegeți comanda **Write Kbd Set to Library** din meniul paginii.

### Suprascrierea aceluiași Set de Sunete de tip User

- Dacă doriți să suprascrieți Setul de Sunete (User Keyboard Set) curent, apăsați doar butonul **OK**.

---

### Salvarea într-o altă locație de Keyboard Set

1. Dacă doriți să salvați într-o altă locație, apăsați butonul **Select** și deschideți fereastra de selecție _Keyboard Set Library_. Alegeți o locație exact așa cum ați alege un Keyboard Set. Locațiile libere (goale) sunt afișate printr-o serie de liniuțe („---”).

2. Când reveniți în fereastra de dialog _Write Keyboard Set_, puteți modifica numele setului.
   Apăsați pictograma de editare text <img src="/images/pa4x/13-editare-avansata-sunete/198-2.jpg" alt="Text edit icon" className="inline-block h-5 mx-1 align-middle" /> pentru a deschide tastatura virtuală și a edita numele.  
    După ce ați terminat de editat numele, confirmați apăsând butonul **OK** de sub tastatura virtuală.

3. Când reveniți în fereastra de dialog _Write Keyboard Set_, confirmați operațiunea de salvare (Write) apăsând butonul **OK**.

### Salvarea Seturilor de Sunete (Keyboard Sets) într-un Stil

Seturile de Sunete pot stoca sunete de la tastatură (Keyboard Sounds) și setări direct în interiorul unui Stil.

Atunci când selectați un Stil, sunt selectate automat patru Seturi de Sunete asociate acelui Stil.
Puteți accesa (rechema) aceste Seturi de Sunete folosind butoanele **KEYBOARD SET** aflate sub ecran.

_Notă: În mod normal, modificările pot fi salvate doar în stilurile de tip Favorite, User și Direct._

#### Deschiderea ferestrei de dialog „Write Keyboard Set to Style” din panoul de control

- În modul Style Play sau Song Play, țineți apăsat oricare dintre butoanele **KEYBOARD SET** de sub ecran timp de aproximativ o secundă.

#### Deschiderea ferestrei de dialog „Write Keyboard Set to Style” de pe ecran (display)

1. În modul Style Play sau Song Play, alegeți comanda **Write Kbd Set to Style** din meniul paginii.

### Salvarea Setului de Sunete (Keyboard Set)

- Dacă doriți să suprascrieți Setul de Sunete curent, apăsați doar butonul **OK**.
- Dacă doriți să salvați Setul de Sunete într-o altă locație din cadrul aceluiași Stil, apăsați săgeata din dreptul parametrului **Kbd Set** pentru a deschide un meniu pop-up și alegeți o altă locație.

2. Puteți modifica numele Setului de Sunete. Apăsați pictograma de editare text <img src="/images/pa4x/13-editare-avansata-sunete/198-2.jpg" alt="Text edit icon" className="inline-block h-5 mx-1 align-middle" />pentru a deschide tastatura virtuală și a edita numele.
   După ce ați terminat de editat numele, confirmați apăsând butonul **OK** de sub tastatura virtuală.
3. Când reveniți în fereastra de dialog _Write Kbd Set to Style_, confirmați operațiunea de salvare (Write) apăsând butonul **OK**.

### Salvarea Seturilor de Sunete (Keyboard Sets) într-o intrare SongBook

Puteți salva modificările aduse sunetelor de la tastatură (Keyboard Sounds) și setărilor aferente într-unul dintre Seturile de Sunete.
Atunci când alegeți o intrare în SongBook (SongBook Entry), sunt selectate automat patru Seturi de Sunete asociate acelei intrări.
Puteți accesa (rechema) aceste Seturi de Sunete folosind butoanele **KEYBOARD SET** aflate sub ecran.

#### Salvarea Seturilor de Sunete într-o intrare SongBook nouă

Puteți crea o intrare nouă în SongBook și, în același timp, puteți salva Seturile de Sunete curente împreună cu aceasta.

1. În timp ce vă aflați în modul Style Play sau Song Play, alegeți Stilul sau Melodia pe care se va baza intrarea din SongBook. Stilul include până la patru Seturi de Sunete.

2. Dacă doriți, editați sunetele de la tastatură și setările acestora (punctul de split, transpunerea pe octave, volumul etc.).
   Acesta va fi Setul de Sunete nr. 1 (Keyboard Set #1).

3. Când ați terminat editarea, țineți apăsat butonul **SONGBOOK** timp de o secundă pentru a deschide pagina _Write Song_.

   <figure className="my-6 text-center">
     <img
       src="/images/pa4x/13-editare-avansata-sunete/200-1.jpg"
       alt="Write Kbd Set to Library dialog"
       className="mx-auto"
     />
     <figcaption />
   </figure>

4. Dacă a fost selectat un SongBook Direct, alegeți între **Internal** și **Direct SongBook**.

5. Apăsați parametrul **New Song Name** și atribuiți un nume intrării.

6. Apăsați butonul **OK** pentru a salva noua intrare în SongBook.

Împreună cu Seturile de Sunete, toate setările curente vor fi salvate în noua intrare din SongBook (inclusiv Stilul sau Melodia selectată).  
Dacă ați editat sunetele de la tastatură (Keyboard Sounds), acestea vor fi salvate ca **Keyboard Set #1**.

---

### Salvarea unui Set de Sunete în intrarea SongBook selectată

Puteți salva sunetele de la tastatură ca un Set de Sunete (Keyboard Set) direct în interiorul intrării selectate din SongBook.

1. Înainte de a edita sunetele, mergeți la pagina **SongBook > Book** sau **Set List** și alegeți intrarea SongBook în care doriți să le salvați.

2. Apăsați butonul **EXIT** pentru a ieși din SongBook.

3. Editați sunetele de la tastatură (Keyboard Sounds).

4. Mergeți la pagina **SongBook > Write**.

   <figure className="my-6 text-center">
     <img
       src="/images/pa4x/13-editare-avansata-sunete/201-1.jpg"
       alt="Write Kbd Set to Library dialog"
       className="mx-auto"
     />
     <figcaption />
   </figure>

5. Bifați caseta **Keyboard Set > Write** și selectați numele setului individual de sunete (**Keyboard Set**).

6. Alegeți o singură locație de Keyboard Set pentru a salva sunetele în locația selectată din cadrul intrării SongBook.
   După ce ați ales locația țintă, puteți atribui un nume nou Setului de Sunete.

7. Apăsați butonul **Write** pentru a afișa fereastra de dialog _Write Song_.

   <figure className="my-6 text-center">
     <img
       src="/images/pa4x/13-editare-avansata-sunete/201-2.jpg"
       alt="Write Kbd Set to Library dialog"
       className="mx-auto"
     />
     <figcaption />
   </figure>

8. Dacă a fost selectat un SongBook Direct, alegeți între **Internal** și **Direct SongBook**.

9. Alegeți dacă doriți să suprascrieți o intrare existentă sau să creați una nouă:
   - Pentru a suprascrie intrarea curentă din SongBook, alegeți **Rename/Overwrite**.
   - Pentru a crea o intrare nouă în SongBook, alegeți **New Song**.

10. Apăsați pe rândul **New Song Name** dacă doriți să editați numele intrării din SongBook.

11. Apăsați **OK** pentru a salva intrarea în SongBook.

12. Dacă doriți să salvați mai multe Seturi de Sunete (Keyboard Sets), repetați procedura de mai sus pentru celelalte patru locații de Keyboard Set din interiorul intrării SongBook.
