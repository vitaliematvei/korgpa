# Ce faci daca pedalele nu functioneaza corect?

Daca observi ca pedalele nu raspund corect, poti face doua verificari esentiale:

- recalibreaza pedalele;
- inverseaza polaritatea pedalei, daca este necesar.

Aceste setari se fac din:

- <span className="font-bold">Global > Controllers > Foot</span>

Dupa aplicarea modificarilor, testeaza din nou pedala pentru a confirma ca
raspunsul este corect.
