# Ce este muzica?

Muzica este organizarea sunetelor in timp. Orice combinatie de sunete care produce o emotie sau un sentiment poate fi considerata muzica.

## Elementele de baza

- **Ritm** — pulsul, bataile regulate care dau energia muzicii
- **Melodie** — succesiunea de note care formeaza o linie muzicala
- **Armonie** — mai multe note cântate simultan

## De ce este important sa inveti muzica?

Intelegerea muzicii iti permite sa canti, sa compui si sa comunici prin sunete — un limbaj universal.
