# Prelucrarea timpilor cu note și pauze

Cel mai bun mod de a înțelege cum influențează pauzele o piesă muzicală este să le vezi amestecate cu notele. Pentru a evita confuzia, în următoarele exerciții vom folosi doar note de patrime.

Cele cinci exerciții prezentate mai jos sunt perfecte pentru a exersa recunoașterea ritmului și pentru a învăța toate tipurile de note și pauze, astfel încât creierul să le citească automat. Fiecare exercițiu conține trei măsuri a câte patru timpi (măsura 4/4).

În fiecare măsură sunt patru timpi. Bate din palme pe note și numără cu voce tare pauzele. Începe să numeri, apoi bate din palme după ce ai ajuns la patru.
